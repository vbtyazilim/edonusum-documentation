Giden Fatura

Giden Fatura Portal API

Portal giden fatura listesi, görüntüleme, e-posta, belge numarası ve mükellef sorgu endpointleri.

Kapsam: Bu endpointler VBT Portal'ın giden fatura ekranlarında kullandığı UI sözleşmeleridir. Sunucudan sunucuya entegrasyon için Giden Fatura Entegratör API sayfasını kullanın.

POST /api/Invoice/GetOutgoingInvoiceGridListSearchUIRequestModel<OutgoingInvoiceGetUiRequestModel>SearchResponseModel<OutgoingInvoiceGridResponseModel>Filtreli ve sayfalı giden fatura gridini döner.
POST /api/Invoice/GetGlobalSearchOutgoingInvoiceListSearchUIRequestModel<GlobalSearchRequestModel>SearchResponseModel<OutgoingInvoiceGridResponseModel>Portal global aramasındaki giden fatura sonuçlarını döner.
