API Temelleri

API Temelleri

Kimlik doğrulama, ortak header, response, hata ve belge kimliği sözleşmeleri.

Başlangıç noktası: Bu sözleşmeler hem giden hem gelen fatura endpointleri için ortaktır. İşleme özgü request ve response alanları yön bazlı API sayfalarında açıklanır.

Kimlik Doğrulama

Önce hesap bilgileriyle token alın. Dönen token'ı sonraki her çağrıda VbtAuthorization header'ına yazın.

POST/api/Account/Token

API oturumu için yetkilendirme token'ı üretir.

RequestTokenRequestModel — Email, Password
ResponseTokenResponseModel — Token
Token JSON örneğini görüntüle
{
  "Email": "entegrasyon@firma.com",
  "Password": "GUCLU_PAROLANIZ"
}

Ortak Header Sözleşmesi

HeaderDeğerKullanım
Content-Typeapplication/jsonJSON request gövdesi taşıyan çağrılarda kullanılır.
VbtAuthorizationToken endpointinden dönen değerToken çağrısı dışındaki korumalı endpointlerde zorunludur.

Response ve Hata Sözleşmesi

API sonuçları işlem verisini Data alanında taşır. Çağrının HTTP olarak tamamlanması, faturanın GİB veya karşı taraf yaşam döngüsünü tamamladığı anlamına gelmez; işleme ait durum endpointi ayrıca izlenir.

KontrolEntegratör davranışı
HTTP başarısıResponse gövdesini ve işlem sonucunu okuyun; yalnız HTTP koduna göre belgeyi tamamlandı saymayın.
Doğrulama/iş kuralı hatasıDönen mesajı request alanıyla eşleştirin, request'i düzelttikten sonra yeniden gönderin.
Timeout veya bağlantı kopmasıAynı belgeyi yeni kimlikle oluşturmadan önce ETTN ya da dış referansla sorgulayın.
Asenkron sonuçGiden veya gelen yönün durum endpointini terminal sonuca kadar izleyin.

KimlikAmaçKalıcı kullanım
