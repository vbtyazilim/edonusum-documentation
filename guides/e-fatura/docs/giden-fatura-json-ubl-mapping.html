Giden Fatura

Giden Fatura JSON → UBL Mapping

Giden fatura JSON alanlarının üretilen UBL Invoice XML içindeki karşılıkları.

Mapping Kapsamı

Kısa kural: Aşağıdaki tablo, AddOutgoingInvoice isteğinin ortak alanlarıyla profile özgü alanlarının UBL Invoice belgesindeki karşılığını birlikte gösterir. Düz XML için AddOutgoingInvoiceByXml, hazır UBL belgesi için AddOutgoingInvoiceByUbl kullanılır. EARSIVFATURA bu rehberin kapsamı dışındadır.
