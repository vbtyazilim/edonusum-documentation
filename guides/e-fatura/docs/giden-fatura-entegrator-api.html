Giden Fatura

Giden Fatura Entegratör API

Giden faturayı doğrulama, oluşturma, güncelleme, gönderme, sorgulama ve durum takibi endpoint sözleşmeleri.

Ön koşul: Aşağıdaki çağrılardan önce API Temelleri sayfasındaki token ve header sözleşmesini uygulayın. Tam JSON gövdeleri için Giden Fatura Request Örnekleri sayfasını kullanın.

Doğrulama, Önizleme ve Oluşturma

Önizleme endpointleri request'i kaydetmeden doğrular ve PDF üretir. Oluşturma endpointleri JSON, hazır UBL, XML metni veya Excel girdisini kabul eder.

JSON request'i doğrular ve kaydetmeden PDF önizlemesi döner.

RequestOutgoingInvoiceRequestModel
ResponseOutgoingInvoicePreviewResponseModel — InvoicePdfFileBytes, HasError, Errors[]

ResponseOutgoingInvoicePreviewResponseModel
