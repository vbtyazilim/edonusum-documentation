Gelen Fatura

Gelen Fatura Portal API

Portal gelen fatura listesi, görüntüleme, okundu bilgisi, e-posta, kabul/red ve itiraz endpointleri.

Kapsam: Bu endpointler VBT Portal'ın gelen fatura ekranlarında kullandığı UI sözleşmeleridir. ERP entegrasyonu için Gelen Fatura Entegratör API sayfasını kullanın.

POST /api/Invoice/GetGlobalSearchIncomingInvoiceListSearchUIRequestModel<GlobalSearchRequestModel>SearchResponseModel<IncomingInvoiceGridResponseModel>Portal global aramasındaki gelen fatura sonuçlarını döner.
