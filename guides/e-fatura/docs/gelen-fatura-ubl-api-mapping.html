Gelen Fatura

Gelen Fatura UBL → API/ERP Mapping

Alınan UBL Invoice alanlarının gelen fatura API yanıtı ve ERP modelindeki karşılıkları.

Okuma yönü: GİB'den alınan UBL Invoice ayrıştırılır ve gelen fatura ayrıntı response'una dönüştürülür. Operasyonel durum alanları UBL'den değil, platformdaki belge kaydından gelir.
