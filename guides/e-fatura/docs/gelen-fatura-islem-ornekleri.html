Gelen Fatura

Gelen Fatura İşlem Örnekleri

Listeleme, durum, kabul/red, ERP işleme ve belge çıktısı için JSON ve ByXml endpointlerine ayrılmış kopyalanabilir request örnekleri.

Kullanım: Her JSON bloğu ilgili endpoint'in gerçek request modeliyle uyumlu, bağımsız ve doğrudan kopyalanabilir tam bir gövdedir.

Belge Alma ve Sorgulama

Örnek 1: İşlenmemiş gelen faturaları listeleme

Endpoint: POST /api/VbtApi/GetIncomingInvoiceList
Body: SearchRequestModel<IncomingInvoiceGetRequestModel> (JSON)

{
  "Skip": 0,
  "Take": 50,
  "OrderByName": "IssueDate",
  "OrderByType": "Descending",
  "Query": {
    "IssueDate": {
      "StartDate": "2026-07-01T00:00:00",
      "EndDate": "2026-07-31T23:59:59"
    },
    "IsErpProcessed": false
  }
}

Endpoint: POST /api/VbtApi/GetIncomingInvoiceListByXml
Body: XmlRequestModel; aşağıdaki XML XmlModel alanına verilir.

<SearchRequestModel>
  <Skip>0</Skip>
  <Take>50</Take>
  <OrderByName>IssueDate</OrderByName>
  <OrderByType>Descending</OrderByType>
  <Query>
    <IssueDate>
      <StartDate>2026-07-01T00:00:00</StartDate>
      <EndDate>2026-07-31T23:59:59</EndDate>
    </IssueDate>
    <IsErpProcessed>false</IsErpProcessed>
  </Query>
</SearchRequestModel>

    <string>3cde8f40-d674-48f6-a784-713b227be2ac</string>
  </EttnList>
</IncomingInvoiceListRequestModel>

Önerilen Çağrı Sırası

  1. Liste sonucundaki ETTN'yi yerel kayıtta tekilleştirin.
  2. Ayrıntıyı ve gerekiyorsa UBL XML aslını alın.
  3. ERP işlemini kendi transaction'ınız içinde tamamlayın.
  4. Uygulama yanıtı gereken profilde kabul veya red gönderin.
  5. Durum endpointini terminal sonuca kadar izleyin.
  6. ERP işlemi başarıyla tamamlandıktan sonra IsErpProcessed=true güncellemesini yapın.
