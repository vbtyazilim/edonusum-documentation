Gelen Fatura

Gelen Fatura İşlem Örnekleri

Listeleme, durum, kabul/red, ERP işleme ve belge çıktısı için tam ve kopyalanabilir JSON örnekleri.

Kullanım: Her JSON bloğu ilgili endpoint'in gerçek request modeliyle uyumlu, bağımsız ve doğrudan kopyalanabilir tam bir gövdedir.

Belge Alma ve Sorgulama

Örnek 1: İşlenmemiş gelen faturaları listeleme

JSON örneğini görüntüle
{
  "Skip": 0,
  "Take": 50,
  "OrderByName": "IssueDate",
  "OrderByType": "Descending",
  "Query": {
    "IssueDate": {
      "StartDate": "2026-07-01T00:00:00",
      "EndDate": "2026-07-31T23:59:59"
    },
    "IsErpProcessed": false
  }
}

Örnek 2: ETTN listesiyle ayrıntıları alma

JSON örneğini görüntüle
{
  "EttnList": [
    "7f8c9726-5e6f-4dc4-a984-f3da76e2a912",
    "3cde8f40-d674-48f6-a784-713b227be2ac"
  ]
}

Örnek 3: Toplu durum sorgulama

JSON örneğini görüntüle
{
  "EttnList": [
    "7f8c9726-5e6f-4dc4-a984-f3da76e2a912",
    "3cde8f40-d674-48f6-a784-713b227be2ac"
  ]
}

Kabul ve Red

Örnek 4: Kabul uygulama yanıtı

JSON örneğini görüntüle
{
  "ForwardForApproveOrReject": "ForwardForApprove",
  "Ettn": "7f8c9726-5e6f-4dc4-a984-f3da76e2a912",
  "ApplicationResponseNote": "Fatura kabul edilmiştir."
}

Örnek 5: Red uygulama yanıtı

JSON örneğini görüntüle
{
  "ForwardForApproveOrReject": "ForwardForReject",
  "Ettn": "7f8c9726-5e6f-4dc4-a984-f3da76e2a912",
  "ApplicationResponseNote": "Sipariş bilgileriyle uyuşmadığı için reddedilmiştir."
}

ERP Mutabakatı ve Belge Çıktıları

Örnek 6: ERP'de işlendi olarak işaretleme

JSON örneğini görüntüle
{
  "Ettn": "7f8c9726-5e6f-4dc4-a984-f3da76e2a912",
  "ErpProcessBranch": "MERKEZ",
  "IsErpProcessed": true
}

Örnek 7: UBL XML içeriklerini alma

JSON örneğini görüntüle
{
  "InvoiceEttns": [
    "7f8c9726-5e6f-4dc4-a984-f3da76e2a912",
    "3cde8f40-d674-48f6-a784-713b227be2ac"
  ]
}

Örnek 8: PDF içeriklerini alma

JSON örneğini görüntüle
{
  "InvoiceEttns": [
    "7f8c9726-5e6f-4dc4-a984-f3da76e2a912"
  ]
}

Önerilen Çağrı Sırası

  1. Liste sonucundaki ETTN'yi yerel kayıtta tekilleştirin.
  2. Ayrıntıyı ve gerekiyorsa UBL XML aslını alın.
  3. ERP işlemini kendi transaction'ınız içinde tamamlayın.
  4. Uygulama yanıtı gereken profilde kabul veya red gönderin.
  5. Durum endpointini terminal sonuca kadar izleyin.
  6. ERP işlemi başarıyla tamamlandıktan sonra IsErpProcessed=true güncellemesini yapın.
