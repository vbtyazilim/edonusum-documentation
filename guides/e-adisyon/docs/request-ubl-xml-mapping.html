API

Request → UBL XML Mapping

Entegratörün gönderdiği JSON alanlarının UBL CreditNote XML'deki karşılığını gösteren referans tablo.

Mapping Kapsamı

OutgoingBillRequestModel alanları UBL 2.1 CreditNoteType belgesine aktarılır. CreditNoteTypeCode değeri request'teki BillTypeCode (ADISYON) ile aynıdır.

Kısa kural: Entegratör kalem ve taraf bilgilerini request alanlarıyla gönderir; AccountingSupplierParty platform tarafından doldurulur ve XML'e de VBT firma profilinden yazılır.
