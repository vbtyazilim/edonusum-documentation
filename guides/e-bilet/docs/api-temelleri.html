API Temelleri

API Temelleri

Kimlik doğrulama, ortak header, response, belge kimliği ve çağrı sözleşmeleri.

Başlangıç noktası: Bu sözleşmeler karayolu, e-Yolcu Listesi, etkinlik ve havayolu REST endpointleri için ortaktır. İşleme özgü request alanları ilgili belge ailesinin API ve örnek sayfalarında açıklanır.

Kimlik Doğrulama

Önce hesap bilgileriyle token alın. Dönen token'ı sonraki korumalı çağrılarda VbtAuthorization header'ına yazın.

POST/api/Account/Token

API oturumu için yetkilendirme token'ı üretir.

RequestTokenRequestModel — Email, Password
ResponseTokenResponseModel — token bilgisi
Token JSON örneğini görüntüle
{
  "Email": "entegrasyon@firma.com",
  "Password": "GUCLU_PAROLANIZ"
}

Ortak Header Sözleşmesi

HeaderDeğerKullanım
Content-Typeapplication/jsonJSON request gövdesi taşıyan çağrılarda kullanılır.
VbtAuthorizationToken endpointinden dönen değerToken çağrısı dışındaki korumalı REST endpointlerinde gönderilir.

Body ve URI Parametreleri

Bütün POST endpointleri JSON gövdesi kullanmaz. Oluşturma ve tarih aralığı sorguları body taşırken bilet/liste durum ve iptal işlemlerinin bir bölümü değeri URI üzerinden alır.

İşlem türüGirdi biçimiÖrnek
Belge oluşturmaJSON bodyHwTicketSave, EventTicketSave, AirwayTicketSave
Yolcu listesi oluşturmaJSON bodyHwPassengerListSave
Durum sorgulamaURI parametresiticketNumber veya passengerListExternalNumber
İptalURI parametresiKarayolunda ticketExternalNumber, etkinlikte ticketNumber
Etkinlik tarih aralığıJSON bodyGetEventTicketDateRangeRequestModel

Response ve Hata Sözleşmesi

REST sonuçları işlem verisini ortak response zarfının Data alanında taşır. Belge oluşturma sonucu bilet numarası ve UUId döndürür; bu sonuç PDF'in veya GİB raporunun tamamlandığı anlamına gelmez.

KontrolEntegratör davranışı
HTTP sonucuYalnız HTTP koduna göre belgeyi başarılı kapatmayın; response gövdesini ve hata listesini okuyun.
HasError ve Errors[]Alan veya iş kuralı hatasını düzelttikten sonra aynı iş kimliğiyle kontrollü yeniden deneyin.
Oluşturma sonucuTicketNumber ve UUId değerlerini kalıcı olarak saklayın.
Asenkron PDFDurum sorgusunda imzalı PDF'in hazır olduğunu görmeden belge bağlantısını nihai çıktı kabul etmeyin.
Timeout veya bağlantı kopmasıYeni dış referansla tekrar oluşturmadan önce mevcut bilet/listeyi sorgulayın.
