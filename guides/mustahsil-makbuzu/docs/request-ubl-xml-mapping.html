API

Request → UBL XML Mapping

Entegratörün gönderdiği JSON alanlarının UBL XML'deki karşılığını gösteren referans tablo.

Mapping Kapsamı

Request modeli, UBL 2.1 CreditNote XML'e çiftçi/alıcı tarafları, ürün kalemleri, belge toplamları, vergi/kesinti toplamları ve tevkifat alanları üzerinden yansır.

Kısa kural: Request tarafındaki ekonomik veri CreditNoteLine, TaxTotal, WithholdingTaxTotal ve LegalMonetaryTotal alanlarında; kimlik verisi ise AccountingSupplierParty ve AccountingCustomerParty altında UBL'e yansır. Müstahsil kesinti kodları TaxTotal.TaxSubtotal içinde de izlenebilir.

Uygulama Notları

Mapping notları, platformun otomatik tamamladığı alanlar ile entegratörün göndermesi gereken alanlar arasındaki sınırı netleştirir.
