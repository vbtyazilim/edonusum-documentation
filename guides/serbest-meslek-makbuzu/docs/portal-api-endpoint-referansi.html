API

Portal API Endpoint Referansı

Portalın listeleme, önizleme, Excel, e-posta, okunma ve mükellef sorgulama işlemleri.

Kapsam: Bu uçlar VBT Portal kullanıcı deneyimini destekler. Belge oluşturma/güncelleme/iptal/PDF/sorgulama uçları için Entegratör API Endpoint Referansı tek kaynaktır — burada tekrarlanmaz.

Excel ile Toplu Oluşturma

POST/api/Smm/AddOutgoingSmmByExcel

Portal’ın Excel şablonundan okunan e-SMM satırlarını toplu olarak işler.

RequestExcelFileRequestModel; dosya içeriği
ResponseList<OutgoingSmmAddExcelResponseModel>; her satır için dış referans, belge kimlikleri ve hata sonucu
Portal davranışıBaşarılı ve başarısız satırlar ayrı değerlendirilir; dosyanın tamamı tek sonuç sayılmaz.

Listeleme ve Arama

POST/api/Smm/GetESMMGridList

e-SMM grid görünümü için sayfalı ve sıralı belge listesini getirir.

RequestSearchUIRequestModel<OutgoingSmmListRequestModel>
FiltrelerETTN, alıcı VKN/TCKN/adı, müşteri kayıtları, belge no, dış referans, tarih, belge/rapor/e-posta/iptal/okunma durumları
ResponseSearchResponseModel<OutgoingSmmGridResponseModel>
POST/api/Smm/GetGlobalSearchESMMList

Portal global aramasında e-SMM kayıtlarını getirir.

RequestSearchUIRequestModel<GlobalSearchRequestModel>
ResponseSayfalı OutgoingSmmGridResponseModel listesi
KullanımModüller arası tek arama kutusundan belgeye ulaşma

Görüntüleme ve Okunma Durumu

POST/api/DocumentPreview/DownloadOutgoingSmmPdf

Portal belge önizleme bileşeni için tekil PDF indirme yanıtı üretir.

RequestDocumentPreviewRequestModel
ResponseDocumentPreviewResponseModel
POST/api/Smm/OutgoingSmmIsRead

Belgenin Portal’da okundu/okunmadı bilgisini günceller.

Request{ Ettn, IsRead }
Responsebool
POST/api/Smm/GetOutgoingSmmLog

Belgenin Portal’da gösterilen işlem geçmişini sayfalı olarak getirir.

RequestSearchRequestModel<SmmLogRequestModel>
ResponseSearchResponseModel<SmmLogResponseModel>
Görülebilen işlemlerOluşturma, görüntüleme, PDF, e-posta, güncelleme ve iptal hareketleri

Belge Numarası Prefixleri

GET/api/Smm/GetOutgingSmmPrefixList?year={year}

Belirtilen yıl için kullanılabilir e-SMM numara prefixlerini getirir.

Parametreyear — belge numarası yılı
ResponseIList<NumberPrefixResponseModel>
Portal kullanımıBelge numara serisinin seçimi veya gösterimi

E-posta İşlemleri

POST/api/Smm/AddMailOutgoingSmmPage

Grid sayfasında seçilen belgeleri belirtilen alıcıya e-posta gönderimine alır.

RequestMailSendRequestModel
Responsebool
POST/api/Smm/AddMailGlobalOutgoingSmm

Global arama seçimindeki belgeleri e-posta gönderimine alır.

RequestGlobalMailRequestModel
Responsebool
GET/api/Smm/ResetOutgoingOutgoingSmmMailQueue?id={mailId}

Tek bir e-posta kaydını yeniden gönderime hazırlar.

POST/api/Smm/ResetOutgoingOutgoingSmmMailQueueList

UUID listesindeki e-posta kayıtlarını yeniden gönderime hazırlar.

Requeststring[] UUID listesi
ResponseList<MailStateResponseModel>; belge bazlı e-posta durumları
Ayrım: E-posta durumu alıcıya teslim sürecini; GİB rapor durumu ise yasal bildirim sürecini gösterir. Portal bu iki durumu ayrı izler.
