Portal API Endpoint Referansı

Portal UI'ın e-Arşiv Fatura grid, e-posta ve iptal/itiraz tamamlama akışlarında kullandığı endpoint sözleşmeleri.

Kapsam: Bu sayfadaki endpointler VBT Portal'ın kendi kullanımı içindir. Add/Update/Cancel/GetPdf/GetSingle/GetList her zaman Entegratör API Endpoint Referansı sayfasında kalır, buraya taşınmaz.
