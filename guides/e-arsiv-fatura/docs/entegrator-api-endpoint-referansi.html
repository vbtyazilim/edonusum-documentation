Entegratör API Endpoint Referansı

Entegratörün doğrudan ERP/API entegrasyonunda kullandığı belge endpointleri, alan sözleşmeleri ve yanıt örnekleri.

Kimlik Doğrulama

API çağrıları, firmanın yetki bağlamı ve oturum token'ı üzerinden ilerler.

💡 Tüm istekler VbtAuthorization header'ı gerektirir. Token almak için POST /api/Account/Token kullanın.
POST/api/Account/Token

Oturum token'ı alır. Tüm diğer endpointler bu token'ı VbtAuthorization header'ında bekler.

RequestTokenRequestModel — { Email, Password }
ResponseTokenResponseModel — { Token }

Ekleme

Yeni fatura oluşturma çağrıları, belge içeriğini ve taraf bilgilerini platforma teslim eder; farklı giriş yöntemleri aynı belge yaşam döngüsüne bağlanır.

POST/api/VbtApi/AddOutgoingInvoice

Yeni bir e-Arşiv Fatura oluşturur ve sisteme kaydeder.

RequestOutgoingInvoiceRequestModel
ResponseResponseModel<OutgoingInvoiceAddResponseModel> — { InvoiceNumber, Ettn, PdfUrl, XmlUrl }

Alt Modeller

BillingReference

Mükerrer/iade ve ÖKC referansı bu model üzerinden taşınır (BillingReferenceRequestModel).

AlanTipAçıklama
InvoiceDocumentReferenceobjectMükerrer/iade — InvoiceTypeCode IADE/TEVKIFATIADE/YTBIADE/YTBTEVKIFATIADE ise zorunlu; DocumentTypeCode=IADE, Id tam 16 karakter olmalı, aynı istekte tekrarlanan Id mükerrer sayılır
AdditionalDocumentReferenceobjectÖKC fiş bilgisi — DocumentTypeCode=OKCBF ile tetiklenir; bu durumda DocumentType=OKCBilgiFisi, Id, IssueDate, DocumentDescription[], Attachment.ExternalReference (string), IssuerParty.EndpointId ve ValidityPeriod.StartDate (=IssueDate ile aynı gün) hepsi zorunlu

WithholdingTaxTotal

Tevkifat bilgisi — belge seviyesinde doldurulabilen bir dizidir; yalnızca InvoiceTypeCode TEVKIFAT/YTBTEVKIFAT/IADE/YTBIADE/SGK/SARJ/SARJANLIK olduğunda kabul edilir.

AlanTipAçıklama
TaxAmountdecimalToplam tevkifat tutarı
TaxSubtotal[].TaxableAmountdecimalTevkifata tabi matrah
TaxSubtotal[].PercentdecimalTevkifat oranı (%) — platformun tanımlı kod/oran eşleşmelerinden biri olmalı, aksi hâlde "Uyumsuz vergi tipi yüzdesi" hatası döner
TaxSubtotal[].TaxCategory.TaxScheme.TaxTypeCodestringTevkifat kodu (örn. 0003 GV STOPAJI)

TEKNOLOJIDESTEK

Yalnızca ProfileId=EARSIVFATURA ile birlikte geçerlidir. Alıcı PartyIdentifications içinde SchemeId=TCKN ile gönderilmeli; her InvoiceLine.Item.AdditionalItemIdentification, SchemeId'si TELEFON veya TABLET_PC olan en az bir kayıt içermelidir.
