Request Örnekleri

Normal satış, internet satışı, ÖKC, tevkifat ve iptal/itiraz senaryoları için JSON ve ByXml endpointlerine ayrılmış kopyalanabilir request örnekleri.

Senaryo Kapsamı

Aşağıdaki fatura örnekleri AddOutgoingInvoice endpoint sözleşmesine göre hazırlanmıştır. Her örnek eksiksiz bir gövdedir; alan adları ve iç içe yapı API sözleşmesiyle aynıdır.

Alan tipi uyarısı: InvoicedQuantity alanı ham sayı değil { "UnitCode": "...", "Value": ... } biçiminde bir nesnedir. Aşağıdaki örneklerde birim ve miktar birlikte gösterilir.
Özel fatura tipleri: SARJ, SARJANLIK, YTBTEVKIFAT, YTBTEVKIFATIADE ve TEKNOLOJIDESTEK için zorunlu alanları Kullanım Senaryoları, alan karşılıklarını Request → UBL XML Mapping sayfasından uygulayın; bu tipler yalnız temel örnek değiştirilerek gönderilmemelidir.
