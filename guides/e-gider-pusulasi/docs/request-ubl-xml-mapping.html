API

Request → UBL XML Mapping

Entegratörün gönderdiği JSON alanlarının UBL XML'deki karşılığını gösteren referans tablo.

Mapping Kapsamı

Request modeli, UBL 2.1 CreditNote XML'e doğrulama sağlayıcısı, alıcı/vekil bilgileri, iade referansı, kargo ve belge satırları üzerinden yansır.

Kısa kural: Entegratör iş kararlarını request alanlarıyla gönderir; platform bu alanları UBL XML node'larına ve GİB rapor alanlarına dönüştürür. Kargo şirketi gibi platform veritabanından tamamlanan alanlarda entegratör yalnızca kod gönderir.

Uygulama Notları

Mapping notları, platformun otomatik tamamladığı alanlar ile entegratörün göndermesi gereken alanlar arasındaki sınırı netleştirir.

DelegateReceiver varsa Contact yeri değişir: Normalde VerificationInfo → AccountingCustomerParty/Party/Contact altına yazılır. Ancak DelegateReceiver dolu gönderildiğinde, VerificationInfo → BuyerCustomerParty/Party/Contact altına yazılır. Bu, GİB raporundaki aliciBilgileri.bilgiDetay alanlarının vekil bilgilerinden alınmasını sağlar.
