IADE — Kargo ile

Kargo iadelerinde doğrulama kodu, kargo şirketi bilgisi ve alıcı kimliği aynı senaryo içinde birlikte ele alınır. JSON çağrısında entegratör yalnız CargoCompanyCode alanını gönderir; VKN, unvan ve yetki belge no gibi kargo şirketi detaylarını platform tamamlar. Bu detaylar entegratör tarafından yalnız hazır UBL çağrısında DeliveryParty içine doğrudan yazılır (bkz. Entegratör API Endpoint Referansı — Kargo Şirketi).

Edge-Case Tablosu

Sınır durumlar, entegrasyonun beklenmeyen kombinasyonlarda nasıl davranacağını önceden görmek için ayrı ele alınır.

#DurumSonuçNeden
E1SATIS + IADE_PROVIDER❌SATIS'te yalnızca SMS_PROVIDER
E2IADE + ReturnedDocRef yok❌IADE'de zorunlu
E3BELGESIZ + kimlik yok❌Kimlik zorunlu
E4Kargo + SMS_PROVIDER veya Type=SMS❌Kargo → sadece IADE_PROVIDER + IADEKODU
E5EARSIV_FATURA + DocumentNumber boş❌Belgeli iadede no zorunlu
E6Aynı ExternalId tekrar❌Tekil zorunlu
E7DelegateReceiver dolu + alan eksik❌Tüm 3 alan zorunlu
E8SATIS + DelegateReceiver❌Vekalet yalnızca IADE
E9SchemeId = VKN❌Tüzel kişi olamaz
E10Kargo + DelegateReceiver + VerificationInfo.Type=SMS❌Kargo → IADEKODU zorunlu
E11SATIS + ReturnedDocRef dolu✅Doğrulanmaz, ancak alan yine de belgeye ve UBL'ye yazılır — SATIS'te bu alan gönderilmemelidir
E12Kargo + PASAPORTNO + bilgiler tam✅Yabancı kargo iade geçerli
E13BELGESIZ + PASAPORTNO✅Yabancı belgesiz geçerli
E14Kargo + DelegateReceiver(PASAPORTNO) + IADEKODU✅Kargo + yabancı vekil geçerli
E15Yüz yüze + PASAPORTNO + SMS_PROVIDER✅Yabancı, Türk GSM hattı var
