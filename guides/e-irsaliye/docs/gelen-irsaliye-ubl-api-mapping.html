Gelen İrsaliye UBL → API/ERP Mapping

Alınan UBL DespatchAdvice alanlarının gelen irsaliye API yanıtı ve ERP modelindeki karşılıkları.

Mapping Kapsamı

Platform, alınan UBL DespatchAdvice belgesini gelen irsaliye response modeline dönüştürür. Aşağıdaki alanlar ERP entegrasyonunun ana sözleşmesidir.

İrsaliye Yanıtı İlişkisi

Yanıt request'indeki DespatchDocumentReference.Id asıl gelen irsaliyeyi; ReceiptLine[].DespatchLineReference.LineId asıl kalemi gösterir. ERP, asıl ETTN ile yanıt ETTN'sini ve satır bağlantılarını ayrı alanlarda saklamalıdır.
