API Temelleri

Kimlik doğrulama, ortak header, response, hata ve belge kimliği sözleşmeleri.

Ortak sözleşme: Bu sayfadaki kimlik doğrulama, hata ve korelasyon kuralları hem giden hem gelen irsaliye endpointleri için geçerlidir.

Kimlik Doğrulama

Önce hesap bilgileriyle token alın. Dönen değeri sonraki korumalı çağrıların VbtAuthorization header'ına yazın.

POST/api/Account/Token

API oturumu için yetkilendirme token'ı üretir.

RequestTokenRequestModel: Email, Password
ResponseTokenResponseModel: Token
Token JSON örneğini görüntüle
{
  "Email": "entegrasyon@firma.com",
  "Password": "GUCLU_PAROLANIZ"
}

HeaderDeğerKullanım
Content-Typeapplication/jsonJSON gövdeli çağrılarda.

Belge Kimlikleri

KimlikAmaçKullanım
UUId / ETTNBelgenin uçtan uca teknik kimliğiDurum, çıktı, silme, güncelleme ve mutabakatta saklanır.
DespatchAdviceExternalIdERP'nin giden belge referansıTekil tutulur; timeout sonrasında aynı iş olayını sorgulamak için kullanılır.
DespatchAdviceNumberGörünen irsaliye numarasıIsDocumentNumberIncluded seçimine göre entegratör veya platform tarafından belirlenir.
ReceiptAdviceExternalIdERP'nin irsaliye yanıtı referansıYanıt tekrarlarını tekilleştirir.
