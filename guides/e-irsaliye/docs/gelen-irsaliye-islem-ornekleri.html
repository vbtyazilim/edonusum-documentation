Gelen İrsaliye

Gelen İrsaliye İşlem Örnekleri

Listeleme, ERP işleme, çıktı alma ve irsaliye yanıtı için JSON ve ByXml endpointlerine ayrılmış kopyalanabilir request örnekleri.

Yeni Gelen Belgeleri Listeleme

Endpoint: POST /api/VbtApi/GetIncomingDespatchAdviceList
Body: SearchRequestModel<IncomingDespatchAdviceGetRequestModel> (JSON)

{
  "Query": {
    "IssueDate": {
      "StartDate": "2026-08-01T00:00:00+03:00",
      "EndDate": "2026-08-01T23:59:59+03:00"
    },
    "IsErpProcessed": false
  },
  "Skip": 0,
  "Take": 100,
  "OrderByName": "IssueDate",
  "OrderByType": "DESC"
}

Endpoint: POST /api/VbtApi/GetIncomingDespatchAdviceListByXml
Body: XmlRequestModel; aşağıdaki XML XmlModel alanına verilir.

<SearchRequestModel>
  <Skip>0</Skip>
  <Take>100</Take>
  <OrderByName>IssueDate</OrderByName>
  <OrderByType>DESC</OrderByType>
  <Query>
    <IssueDate>
      <StartDate>2026-08-01T00:00:00+03:00</StartDate>
      <EndDate>2026-08-01T23:59:59+03:00</EndDate>
    </IssueDate>
    <IsErpProcessed>false</IsErpProcessed>
  </Query>
</SearchRequestModel>

ERP İşleme Durumu

Bu çağrıyı yalnız ERP kaydı başarıyla tamamlandıktan sonra gönderin.

Endpoint: POST /api/VbtApi/UpdateIncomingDespatchAdviceErpProcessStatus
Body: DespatchAdviceErpProcessRequestModel (JSON)

{
  "Ettn": "aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee",
  "ErpProcessBranch": "MERKEZ",
  "IsErpProcessed": true
}

Endpoint: POST /api/VbtApi/UpdateIncomingDespatchAdviceErpProcessStatusByXml

<DespatchAdviceErpProcessRequestModel>
  <Ettn>aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee</Ettn>
  <ErpProcessBranch>MERKEZ</ErpProcessBranch>
  <IsErpProcessed>true</IsErpProcessed>
</DespatchAdviceErpProcessRequestModel>

Tam Kabul Yanıtı

Yanıt penceresi: GİB uygulama kılavuzu irsaliye yanıtını fiili sevkten başlayan yedi günlük pencereyle sınırlar. Gelen belge response'undaki kalan süreyi izleyin; eksik teslim veya red varsa request'i süre dolmadan gönderin. Tam teslimde yanıt vermek isteğe bağlıdır.

Endpoint: POST /api/VbtApi/AddOutgoingReceiptAdvice
Body: ReceiptAdviceRequestModel (JSON)

{
  "ReceiptAdviceExternalId": "ERP-RCP-20260801-0001",
  "IssueDate": "2026-08-01T15:00:00+03:00",
  "CopyIndicator": false,
  "LineCountNumeric": 1,
  "IsDocumentNumberIncluded": false,
  "DespatchDocumentReference": {
    "Id": "aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee",
    "IssueDate": "2026-08-01T09:00:00+03:00",
    "DocumentType": "DESPATCHADVICE"

    {
      "Id": "1",
      "ReceivedQuantity": { "UnitCode": "C62", "Value": 10 },
